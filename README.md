# Website PCM Berbah ☘️

Sistem Informasi Keuangan, Wakaf, Keanggotaan, dan Profil Pimpinan Cabang Muhammadiyah Berbah.

## Tech Stack
*   **Frontend**: Nuxt.js (Vue 3) + Tailwind CSS
*   **Backend**: Express.js + MongoDB (MEVN Stack)
*   **Deployment**: Hostinger (Frontend Statis & VPS Node.js)

## Struktur Folder Monorepo
*   `/docs` : Berisi dokumentasi sistem (ERD, DFD, Kontrak API).
*   `/frontend` : *Source code* Nuxt.js untuk UI/UX.
*   `/backend` : *Source code* Express.js (dikelola oleh tim BE).

## Cara Menjalankan Frontend
1. Masuk ke folder frontend: `cd frontend`
2. Install dependencies: `npm install`
3. Jalankan server lokal: `npm run dev`
